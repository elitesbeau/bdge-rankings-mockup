G Variants — Polished Pill Rows

Five takes on Mockup G. All keep the rounded-pill row anatomy you liked. They differ in how they fill the middle and what visual signal they bake into each row. Same data in each so you can compare apples-to-apples. bigboard.html untouched.

// G1 Polished Spacing

Same anatomy as G with three fixes: name + pos + team are grouped left (no gap between them), ADP is a single number (no awkward "2 (2.10)"), and the "Coming Soon" props column is replaced with the BDGE verdict pill. Cleanest interpretation of G.

// G2 Verdict-Tinted Rows

Same as G1, but the entire row gets a soft tint and a 4px left stripe driven by the verdict. Steals = green, reaches = pink, even = neutral. Now the page has a vertical rhythm — your eye scans for the green stripes down the column and instantly sees every steal. Zero new data, just visual scan.

// G3 Mini Chip Trio

// G4 Editorial Sub-Line
