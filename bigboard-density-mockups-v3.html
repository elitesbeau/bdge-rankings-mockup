// MOCKUP I Tier Bands

Players are grouped into tier-colored full-width bands — Tier 1 is green-headed, Tier 2 is blue, etc. Each band header has a one-line tier description ("locked-in elite — draft regardless of value") so users know what the tier means. Inside, rows are dense like BDGE.co. The colored band headers give the whole page vertical rhythm without any dead space.

// MOCKUP J Delta Bar — Visual ADP vs BDGE

The middle of each row is a diverging bar chart. Center line = even. Bars going LEFT (green) = BDGE values them higher than market = STEAL. Bars going RIGHT (red) = REACH. The bar length encodes how much. One glance down the page tells you every steal and every reach without reading a single number.

// MOCKUP K Tag Strip — Packed Chips

The middle is a packed strip of colored chips: tier, positional rank, trend (rising / falling / flat), verdict. Like glancing at a baseball card. Chips are left-anchored so the row never has a void — the eye moves continuously from name to chips to ADP.
