Big Board — Distributed Spacing

Different problem: info should feel evenly spread across the full width, not anchored to the sides with a void. Solution: more content in equal-weight sections — tier, positional rank, trend, team, ADP, verdict — each in their own labeled column or chip slot. Three executions below, same data in each.

// M1 Dashboard Cells

The row is a series of labeled stat cells separated by thin vertical dividers — like a sports broadcast scoreboard. Each cell: tiny eyebrow label above, value below. Cells are equal width so the row has consistent rhythm. The player cell is slightly wider to accommodate names; everything else (Team / Tier / Pos / Trend / ADP / Verdict) is 1fr.
